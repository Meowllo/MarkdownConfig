# .mc 语法速查（源自 MarkdownConfig SPEC v0.7.0）

## 文件与兼容性

* 后缀 `.mc`，内容为 Markdown 超集：CommonMark 兼容正文 + 少量 HTML 注释标记。
* 现有 `.md` 升级：改名为 `.mc` 并添加标记即可，无需重写。
* 标准 Markdown 渲染器（GitHub 等）可正常渲染：HTML 注释自动隐藏，**值即所见文本**。
* 约定：`NAME` 匹配 `[A-Za-z_][A-Za-z0-9_.]*`（支持点号命名空间；非 ASCII 名字非法）。

## @var 单变量

```
<!--@var NAME [type=TYPE]-->VALUE<!--@/var-->
```

* `VALUE`：两标记之间的文本，trim 后取值。
* `TYPE`（可选）：`string | number | int | boolean | json | text`；缺省自动推断（`42`→number，`true`→boolean，`[1,2]`→array，`{"a":1}`→object，`"abc"`→string，其余→string）；`int` 要求整数。
* **值含换行时必须以 `type=json` 或 `type=text` 声明**，否则报错。

示例：`连接超时：<!--@var TIMEOUT_MS-->3000<!--@/var-->毫秒` → 渲染显示「连接超时：3000 毫秒」，导出 `{ "TIMEOUT_MS": 3000 }`。

## @table 表格

```
<!--@table NAME-->
| id | 列2 |
| --- | --- |
| a | 1 |
| b | 2 |
<!--@/table-->
```

* 两个标记都必须**独占一行**（允许首尾空白）。
* **第一列固定为 id 列**：必须非空、为标量、逐行唯一；id 列不进入行数据。
* 读出为对象：`{ "NAME": { "a": { "列2": 1 }, "b": { "列2": 2 } } }`。
* 表头 = 键（表头名不进配置）；单元格类型自动推断（同 @var；空单元格 → `null`）。
* 表格至少需要两列。
* 报错：列名重复 / 缺表头或分隔行 / 行单元格数不一致 / id 为空 / id 重复 / id 不是标量。

### 表格单元格内联标记（四种形态）

| 整格形态 | 读出值 |
| --- | --- |
| 格内出现**无名** `@array` | **整格按数组体切分**（文本段与组均按 `/` 分隔） |
| 恰好一个**具名**内联标记 | **裸值**（不包 `{名:值}`）；标记外的文本是人读注释 |
| 两个及以上具名内联标记 | 对象 `{ NAME: 值, … }`，每个标记都必须有名字 |
| 整格无标记 | 纯文本按 JSON 推断（`1/2/3` **不**切成数组） |

```
| a | <!--@var A-->2<!--@/var--> |                    → 2
| b | <!--@array X-->1/2/3<!--@/array--> |            → [1,2,3]
| c | <!--@var X-->1<!--@/var--> <!--@var Y-->2<!--@/var--> | → { "X":1, "Y":2 }
| d | <!--@range R-->1~5<!--@/range--> 超时区间 |     → { "min":1, "max":5 }（"超时区间"是人读注释）
| e | 名称/版本/<!--@array-->格式甲/格式乙<!--@/array--> | → ["名称","版本",["格式甲","格式乙"]]
```

* 移除标记后若仍残留 `<!--@`（未闭合 / kind 错配，如 `@var` 用 `@/array` 关闭）→ 报错。
* 表格内联标记不产生顶层条目；裸文本 `1/2/3` 不会被当数组。

## @array 数组

```
<!--@array NAME [type=TYPE]-->1/2/3/4<!--@/array-->
```

* 元素以 `/` 分隔、trim；缺省逐元素自动推断（可混合类型，`1/a/true` → `[1,"a",true]`）。
* `TYPE`（可选）强制每个**叶子元素**类型，如 `type=string` 时 `1/2/3` → `["1","2","3"]`。
* 空值 → `[]`；可跨行（换行仅作空白）。
* 元素本身含 `/` 时，改用 `@var NAME type=json` 写标准 JSON 数组。

**嵌套**（只能嵌套 `@array`）：

```
<!--@array A--> 1/2/<!--@array -->3/4/5<!--@/array--><!--@/array-->
⇒ "A": [1, 2, [3, 4, 5]]              # 无名嵌套 → 裸子数组

<!--@array A--> 1/2/<!--@array B-->3/4/5<!--@/array--><!--@/array-->
⇒ "A": [1, 2, { "B": [3, 4, 5] }]     # 具名嵌套 → 对象元素
```

* 顶层 `@array` **必须命名**；无名写法只用于嵌套（或表格单元格内，见上）。
* 数组体内出现内联 `@var`/`@range` → 报错；同一父数组内嵌套名重复 → 报错。
* 表达「若干单位，其中某一组是等价候选项」时用嵌套，**不要拍平**（拍平会改变选中概率）。

## @range 区间

```
<!--@range NAME-->1~5<!--@/range-->
```

* 读出为 `{ "NAME": { "min": 1, "max": 5 } }`。
* 以 `~` 分隔（支持全角 `～`）；两端必须都是数字，允许 `**bold**` 包裹。
* 必须单行；`1?5`、缺端、任一端非数字 → 报错。支持顶层与表格内联。

## 评论（评论就是正文）

约定统一放在文档末尾的「评论」区块，但位置不做强制校验：

```
## 评论

<!--@comment target=server.port-->线上是 9090，需确认<!--@/comment-->
```

* 一条评论只含**目标 + 文本**：`<!--@comment target=目标-->文本<!--@/comment-->`。
  标记是 HTML 注释（渲染隐藏），**文本渲染时可见**。
* `target`：变量名 / 表名 / `表.id[.列]` / 块 id（可带前导 `^`；不能含空白）。
  **目标可以重复**——多条评论指向同一个块互不冲突；目标不做存在性校验。
* **append-only**：`mc comment` 只追加到最后一条评论之后；`mc resolve <序号>` 直接删除该条。
* **不进配置**：`mc export` 输出里没有评论。`mc comments` 返回 `{index, target, text, line}`。
* 不能写在表格单元格里，也不能嵌套在别的标记里。

## 普通注释与围栏

* 无 `@` 前缀的 `<!-- ... -->` 完全忽略，不产生变量。
* 围栏代码块（``` 或 ~~~）内的标记被忽略，不作为配置。
* **想展示标记本身（写示例）必须放进围栏**：直接写在正文里会被当成真配置，且多半以「关闭标记缺少开始标记」报错（该报错会附"请放进围栏"的提示）。

## 块 ID（评论锚定与跳转）

* 行尾 `^id`（Obsidian 风格），或 `^id` 独立一行紧跟块后。
* 示例：`# 产品需求 ^p1`、段落后跟一行 `^b12`。
* config 变量 / 表格本身可用 `NAME` 作为锚点。

## 错误规则（fail loud）

| 情况 | 行为 |
| --- | --- |
| 标记未闭合 / 错配 / 嵌套非法 | 报错（含行号） |
| 正文里写了标记却没配对（多半是想写示例） | 报错，并附「放进围栏」提示 |
| 顶层 `@array` 未命名 | 报错 |
| `@array` 内嵌套 `@var`/`@range`、同层嵌套名重复 | 报错 |
| 同名变量重复声明 | 报错（`mc export --allow-override` 时后者覆盖） |
| 点号命名空间与标量冲突（`site.title` 与 `site` 并存） | 报错 |
| 值含换行但未声明 `type=json/text` | 报错 |
| 表格列名重复 / 结构不完整 / 只有一列 | 报错（指向具体行） |
| 表格 id 为空 / 重复 / 不是标量 | 报错（指向具体行） |
| 表格内联标记未闭合 / kind 错配 / 多标记未命名 / 标记名重复 | 报错 |
| `@var/@array` 出现在 `@table` 区域（单元格内联除外）、`@table` 出现在 `@var/@array` 值内 | 报错 |
| `@table` 表名非法（非 ASCII / 不匹配 `[A-Za-z_][A-Za-z0-9_.]*`） | 报错，指到 open 行（#2） |
| `@range` 值非法（非 `数字~数字`、缺端、跨行） | 报错（含行号） |
| 评论缺 `target` / `target` 含空白 / 内容为空 / 未闭合 | 报错（含行号） |
| 评论写在表格单元格里或嵌套在别的标记里 | 报错 |
| 同一错误被重复收集 | 按 `行:消息` 去重，只打印一次（#6） |

## canonical 输出

* `mc export` 输出：键名递归排序、2 空格缩进 JSON；同输入永远同输出（字节稳定）。
* 这是跨语言移植（Tier 2）的一致性校验基准。

## tables 与 fingerprint

* `mc tables <file> [--all]`：列出已标记表（名 / id 行数 / 行区间）与未标记表计数。
* `mc export --fingerprint`：顶层加 `$fingerprint`：
  * `sha256` = `sha256(JSON.stringify(源文本))` —— **源文本**的哈希，**不是**文件字节。
  * `sha256File` = **文件字节**的 sha256（可直接 `shasum -a 256` 复算）。
  * `mcVersion`；`generatedAt`（会破坏字节稳定，要可复现就加 `--no-timestamp`）。
* 下游忽略 `$` 前缀键，可用任一哈希做来源过期门禁。
